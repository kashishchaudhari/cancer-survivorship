06 · Data & reliability

Understand the evidence behind each view

Complete supplied files, explicit selection rules, confidential research

What data is being used?

The original supplied ZIP contains raw Brain, Breast, Liver, Prostate and Skin extracts plus separate derived workbooks. The raw-data modules read the text members directly, using all eligible records. The original suicide-survival module still uses the earlier outcome-stratified workbook.

Complete supplied archive does not mean the complete SEER registry. The original registry selection, export filters, submission version and observation cutoff require source-owner confirmation. Cross-extract patient linkage also assumes a common identifier namespace.

What validation establishes

Schema and numerical checks test aggregate consistency. Synthetic unit tests verify edge cases and confidentiality safeguards. A separate local source validator reconstructs patient counts and descriptive cells from the ZIP, then recalculates survival, Greenwood confidence intervals and at-risk counts independently. Source fingerprints make the input files identifiable.

Passing these checks means the defined calculations agree. Sampling bias, confounding, missing treatment information and informative censoring can remain.

What remains unvalidated

The model test fold has been reused for configuration comparisons. There is no external clinical validation or demonstrated treatment-recommendation benefit. Variable follow-up makes the binary outcome different from a personal risk within a specified period. Post-diagnosis treatment and stage fields cannot automatically be used as diagnosis-time predictors.

Reliable calculations are one layer of evidence. Clinical prediction and causal treatment effects require separately justified study designs and validation.

Read the fields carefully

Age is banded. Area median income is not individual income. Summary stage is not an AJCC stage group. No/unknown treatment is not confirmed non-treatment. The top-coded timing value means 731+ days; management timing can include active surveillance. Unknown values are retained or explicitly excluded with a stated denominator.

Confidentiality is part of the study

Raw data, aggregates, results, reports and data-backed screenshots remain local. Small-cell suppression does not grant permission to distribute them. Hosted CI uses invented fixtures only and has no artifact-upload or Pages-deployment step. Real-data sharing requires permission for the data and destination.
